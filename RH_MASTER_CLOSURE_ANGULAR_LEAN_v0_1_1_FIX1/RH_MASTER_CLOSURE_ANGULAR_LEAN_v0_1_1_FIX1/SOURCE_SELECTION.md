# Source selection

The master package keeps actual-function definitions and explicit remaining
premises. An archive name containing "closure" or "A-Tier" is not evidence of
an unconditional RH theorem.

| Attached source | Selection |
| --- | --- |
| 36 — RH angular master chain | Canonical complete angular equivalence chain and its actual Hadamard dependencies. |
| 34 — QQRH full-x anchor 2 | Fourteen unique modules, preserving height and full-angle radius improvements. Shared reduced copies are superseded by 36. |
| 38 — Angular regularity FIX9 | All mathematical source modules; this is the user-reported passing regularity baseline. |
| 19 — A-Tier RH equivalence | Nine mathematical modules: actual Cayley/GolPhi equivalences and independent kernel identities. |
| 07, 08, 16, 17, 18 | Compatible native SOLOBOLO, local-pole, row, Cayley-trace, and entire-product/ODE routes; duplicates deduplicated by source bytes. |
| 23 — AWPI final portable | Twenty-five modules supporting the canonical scalar/tail native-RH equivalences. |
| 02 — Hausdorff strong identities | Only three self-contained modules: finite differences, passivity ledgers, finite hierarchies. |

All shared xi/theta proof declarations use the FIX9/36 sources. The older
package18 XiCore differs only by its broad Mathlib import; the canonical
source is retained. Different namespace representatives of actual xi/theta
are related by definitional-equality theorems in the master interface.

The excluded sources remain untouched in the supplied archives. No missing
bridge is replaced by an axiom, opaque RH declaration, or placeholder proof.

## Changes in this release

The source proofs retained from the archives are copied without proof edits,
except FIX1's explicit multiplication-cast rewrite in
`AWPIRH/NativeCompletionReduction.lean`. Its theorem statement is unchanged.
The newly written `RHMaster/` files perform definitional alignment, compose
existing routes, and prove the explicit unbounded-slope and stationary-point
reductions. `Main.lean`, `AllSources.lean`, the audit, and the runner are new
assembly infrastructure. Every new theorem is pending compilation.

Third-party attribution from the angular source bundle is preserved under
`THIRD_PARTY_LICENSES/`, with its source metadata under `provenance/`.
