Lean 4.33.0 Linux self-location compatibility record
===================================================

Observed startup failure
  Official bin/lean --version: error: failed to locate application
  Python os.readlink('/proc/self/exe'): succeeds
  Python os.readlink('/proc/' + str(os.getpid()) + '/exe'): PermissionError(13)

Official source inspected
  https://raw.githubusercontent.com/leanprover/lean4/v4.33.0/src/runtime/io.cpp
  lean_io_app_path constructs /proc/<getpid()>/exe and calls readlink.
  src/lean/Lean/Util/Path.lean getBuildDir calls IO.appDir unconditionally.
  Its initSearchPathInternal calls getBuildDir before command-line processing.
  LEAN_SYSROOT controls external installation lookup, not this startup call.

Compatibility adapter
  lean_self_path_compat.c / lean_self_path_compat.so
  A libc readlink interposer compares the requested path with exactly
  /proc/<the calling process's current getpid()>/exe. Only an exact match is
  translated to /proc/self/exe, the permitted standard alias for that same
  calling process. All other paths pass unchanged to libc readlink.
  No other process, inaccessible file, or privileged information is accessed.
  No Lean executable/library, elaborator, kernel, or trust option is changed.

Build
  cc -shared -fPIC -O2 -Wall -Wextra -o lean_self_path_compat.so lean_self_path_compat.c -ldl

Usage
  Set LD_PRELOAD to the absolute path of lean_self_path_compat.so for the
  unmodified official Lean or Lake command and its compiler subprocesses.
